Notes on the plan's sketch:
- The plan's positional-reference wording "the first one" is a false positive (`js-functions-11` legitimately says "parameters before the first one with a default"). The regex below only matches `option|choice|answer` nouns.
- `POSITIONAL`, `KNOWN_LANGS` and `LIMITS` are exported so `content/lint.test.js` can pin them.
- The "is this the entry file" check compares `path.resolve(process.argv[1])` with `fileURLToPath(import.meta.url)`, case-insensitively on win32. The plan's `pathToFileURL(argv[1]).href === import.meta.url` is also fine on Windows in practice, but drive-letter casing differs between shells; the version below is robust to that.

**Why an error rather than a warning for position skew.** A learner notices "it is always B" in the first module; that makes 93% of the quiz a free answer, which defeats the spaced-repetition premise. A warning that fires on 31/31 modules is ignored on day two. The right *product* fix is shuffling choices at serve time (`sessions.js`/`publicQuestion` returning a per-session order and grading through it), but that is a runtime change and out of this plan's scope. The content fix is mechanical and safe:

**One-off rebalance (`rebalance-choices.mjs`, §6, not committed).** For each `mcq`/`output` block in `content/questions/*.js`, in file order per module, it rotates the `choices` array so the correct answer lands on a cycling target position (2,0,3,1,…) and rewrites `answer:`. Rotation preserves the authors' relative order (a wrap, not a shuffle). Questions with an anchored choice ("all/none/both of the above/these") are skipped. It then re-imports the package **in a child process** (the module cache otherwise lies) and verifies, for every question, that the choice set and the correct choice's *text* are unchanged and nothing else moved. Tested on a scratch copy of `content/`: 303 rotated, 1 skipped (`data-sql-12`), verification passed, `node --check` passed on all 9 files, resulting histogram `#1 26% / #2 22% / #3 28% / #4 24%`, worst module 31%, lint errors drop from 41 to 5 (the four retypes + booleans). Run it *after* the other agent's content edits land (it finds blocks by `id:`, so it is robust to prompt/why edits), then skim the diff for choice lists that read as an ordered sequence.

`content/stats.js` (§6) adds two columns the plan lacks: `topPos` (which index and its share) and `longest` (share where the correct choice is strictly longest), plus the global position histogram and boolean split.

### 6.19 `content/lint.js` (full, tested against HEAD content)

```js
/**
 * Content lint: authoring-quality checks that go beyond the structural
 * validation in `validateContent()`.
 *
 *   node content/lint.js            errors fail (exit 1), warnings print
 *   node content/lint.js --strict   warnings fail too
 *
 * `lintContent()` is a pure function over `{ modules, questions }` so tests can
 * feed it small fixtures; the CLI at the bottom runs it over the real curriculum.
 */

import path from 'node:path';
import { fileURLToPath } from 'node:url';

import { modules, questions, validateContent } from './index.js';

export const LIMITS = {
  minWhy: 120,
  minPerModule: 10,
  maxPerModule: 25,
  minPrimerWords: 300,
  maxPrimerWords: 900,
  minObjectives: 3,
  maxObjectives: 6,
  // Correct-answer position. With four choices, chance is 25%; anything a
  // learner can exploit ("it's always B") fails the module.
  maxPositionShare: 0.4,
  minPositionSample: 8,
  // True/false questions across the whole curriculum: the rarer answer must
  // still be at least this share, otherwise "always false" is a strategy.
  minBooleanMinority: 0.3,
  minBooleanSample: 10,
  // "The longest answer is right" is the other classic tell. Warning only:
  // fixing it means rewriting distractors, which is authoring, not tooling.
  maxLongestShare: 0.5,
};

/** Languages `client/src/components/Code.tsx` can highlight. Keep in sync with KEYWORDS there. */
export const KNOWN_LANGS = new Set(['js', 'jsx', 'ts', 'tsx', 'json', 'csharp', 'sql', 'bash']);

const norm = (s = '') => s.toLowerCase().replace(/\s+/g, ' ').trim();
const pct = (n, d) => `${Math.round((100 * n) / d)}%`;

// "option 3", "choice B", "the last option": explanations must name the
// choice, not its position, or any reordering silently makes them wrong.
export const POSITIONAL =
  /\b(?:option|choice|answer)\s+(?:[a-f]|[1-6]|one|two|three|four|five|six)\b|\bthe\s+(?:first|second|third|fourth|fifth|last)\s+(?:option|choice|answer)\b/i;

const isSingleAnswer = (q) => (q.type === 'mcq' || q.type === 'output') && typeof q.answer === 'number';

/**
 * @param {{ modules: import('./types.d.ts').Module[], questions: import('./types.d.ts').Question[] }} content
 * @param {Partial<typeof LIMITS>} [overrides]
 * @returns {{ errors: string[], warnings: string[] }}
 */
export function lintContent({ modules, questions }, overrides = {}) {
  const limits = { ...LIMITS, ...overrides };
  const errors = [];
  const warnings = [];

  /* ------------------------------------------------------------ questions */

  const seenFull = new Map(); // prompt + code
  const seenBare = new Map(); // prompt only, for questions with no code
  for (const q of questions) {
    const full = `${norm(q.prompt)}|${norm(q.code)}`;
    if (seenFull.has(full)) errors.push(`${q.id}: duplicates ${seenFull.get(full)} (same prompt and code)`);
    else seenFull.set(full, q.id);

    if (!q.code) {
      const bare = norm(q.prompt);
      if (seenBare.has(bare)) errors.push(`${q.id}: duplicates ${seenBare.get(bare)} (same prompt, no code)`);
      else seenBare.set(bare, q.id);
    }

    if (q.choices) {
      const texts = q.choices.map((c) => norm(c.text));
      if (new Set(texts).size !== texts.length) errors.push(`${q.id}: duplicate choices`);
    }
    if (!q.tags?.length) errors.push(`${q.id}: no tags`);
    if (q.why.length < limits.minWhy) errors.push(`${q.id}: why is ${q.why.length} chars (< ${limits.minWhy})`);
    if (q.type === 'output' && !q.code) errors.push(`${q.id}: output question without code (make it mcq)`);
    if (q.code && !KNOWN_LANGS.has(q.lang)) errors.push(`${q.id}: lang "${q.lang}" is not highlightable`);

    const positional = POSITIONAL.exec(q.why);
    if (positional) errors.push(`${q.id}: why refers to a choice by position ("${positional[0]}")`);

    if (q.type === 'short' && q.answer.length < 2) warnings.push(`${q.id}: short answer accepts only one spelling`);
  }

  /* -------------------------------------------------------------- modules */

  for (const m of modules) {
    const qs = questions.filter((q) => q.moduleId === m.id);
    if (qs.length < limits.minPerModule || qs.length > limits.maxPerModule) {
      errors.push(`${m.id}: ${qs.length} questions (want ${limits.minPerModule}-${limits.maxPerModule})`);
    }

    const words = m.primer.split(/\s+/).filter(Boolean).length;
    if (words < limits.minPrimerWords) errors.push(`${m.id}: primer is ${words} words (< ${limits.minPrimerWords})`);
    if (words > limits.maxPrimerWords) errors.push(`${m.id}: primer is ${words} words (> ${limits.maxPrimerWords})`);
    if (!/^##\s/m.test(m.primer)) errors.push(`${m.id}: primer has no ## headings`);
    for (const [, lang] of m.primer.matchAll(/^```(\w+)/gm)) {
      if (!KNOWN_LANGS.has(lang)) errors.push(`${m.id}: primer code fence uses unknown lang "${lang}"`);
    }

    if (m.objectives.length < limits.minObjectives || m.objectives.length > limits.maxObjectives) {
      errors.push(`${m.id}: ${m.objectives.length} objectives (want ${limits.minObjectives}-${limits.maxObjectives})`);
    }
    for (const objective of m.objectives) {
      for (const [, term] of objective.matchAll(/`([^`]+)`/g)) {
        if (!m.primer.includes(term)) warnings.push(`${m.id}: objective term \`${term}\` is not in the primer`);
      }
    }

    for (const d of [1, 3]) {
      if (!qs.some((q) => q.difficulty === d)) warnings.push(`${m.id}: no d${d} questions`);
    }

    const single = qs.filter(isSingleAnswer);
    if (single.length >= limits.minPositionSample) {
      const hist = new Map();
      let longest = 0;
      for (const q of single) {
        hist.set(q.answer, (hist.get(q.answer) ?? 0) + 1);
        const lengths = q.choices.map((c) => c.text.length);
        const max = Math.max(...lengths);
        if (lengths[q.answer] === max && lengths.filter((l) => l === max).length === 1) longest += 1;
      }
      const [topIndex, topCount] = [...hist.entries()].sort((a, b) => b[1] - a[1])[0];
      if (topCount / single.length > limits.maxPositionShare) {
        errors.push(
          `${m.id}: correct answer is choice ${topIndex + 1} in ${topCount}/${single.length} single-answer questions (${pct(topCount, single.length)} > ${pct(limits.maxPositionShare, 1)})`,
        );
      }
      if (longest / single.length > limits.maxLongestShare) {
        warnings.push(
          `${m.id}: correct choice is the longest in ${longest}/${single.length} (${pct(longest, single.length)}); rewrite distractors`,
        );
      }
    }
  }

  /* --------------------------------------------------------------- global */

  const bools = questions.filter((q) => q.type === 'boolean');
  if (bools.length >= limits.minBooleanSample) {
    const trues = bools.filter((q) => q.answer === true).length;
    const minority = Math.min(trues, bools.length - trues);
    if (minority / bools.length < limits.minBooleanMinority) {
      errors.push(
        `boolean questions are ${trues} true / ${bools.length - trues} false; the rarer answer must be at least ${pct(limits.minBooleanMinority, 1)}`,
      );
    }
  }

  return { errors, warnings };
}

/* ------------------------------------------------------------------- CLI */

function isMain() {
  if (!process.argv[1]) return false;
  const entry = path.resolve(process.argv[1]);
  const self = fileURLToPath(import.meta.url);
  return process.platform === 'win32' ? entry.toLowerCase() === self.toLowerCase() : entry === self;
}

if (isMain()) {
  const { counts } = validateContent(); // throws on structural problems
  const { errors, warnings } = lintContent({ modules, questions });
  const strict = process.argv.includes('--strict');
  for (const w of warnings) console.warn(`  warn   ${w}`);
  for (const e of errors) console.error(`  error  ${e}`);
  console.log(
    `${counts.questions} questions in ${counts.modules} modules: ${errors.length} error(s), ${warnings.length} warning(s)${strict ? ' (strict)' : ''}`,
  );
  process.exit(errors.length || (strict && warnings.length) ? 1 : 0);
}
```

### 6.21 `rebalance-choices.mjs` *(one-off; run from anywhere, do not commit)*

Tested end to end on a scratch copy (see §5). Usage: `node rebalance-choices.mjs <path-to-content> --write`.

```js
/**
 * One-off: rotate the choices of every single-answer question so the correct
 * answer is no longer at index 1 in 93% of questions. Run once, verify, commit
 * the content change.
 *
 *   node rebalance-choices.mjs <content-dir> [--write]
 *
 * Without --write it only reports. It rewrites the source text of
 * content/questions/*.js in place (only the `choices: [...]` array and the
 * `answer: N` line of each affected q({...}) block), then re-imports the
 * package in a child process to verify that every question kept the same
 * choice set and the same correct-choice text.
 */

import { execFileSync } from 'node:child_process';
import fs from 'node:fs';
import path from 'node:path';
import { pathToFileURL } from 'node:url';

const [, , contentDir, ...flags] = process.argv;
if (!contentDir) throw new Error('usage: node rebalance-choices.mjs <content-dir> [--write]');
const write = flags.includes('--write');
const dir = path.resolve(contentDir);

// Target positions cycle per module in file order, so every module ends up
// close to uniform (max share = ceil(n/4)/n) rather than merely random.
const CYCLE = [2, 0, 3, 1];

/** Import the package in a child process so the module cache never lies to us. */
function snapshot() {
  const code = `import(${JSON.stringify(pathToFileURL(path.join(dir, 'index.js')).href)}).then((m) => process.stdout.write(JSON.stringify(m.questions)))`;
  return JSON.parse(execFileSync(process.execPath, ['--input-type=module', '-e', code], { maxBuffer: 64 * 1024 * 1024 }));
}

// Choices that only make sense in last place stay untouched.
const ANCHORED = /\b(?:all|none|both|neither|any|each)\s+of\s+(?:the\s+)?(?:above|these|them)\b/i;

/** Scan a JS array literal starting at `[`; returns { elements, end, multiline, indent, closeIndent }. */
function readArray(src, open) {
  let i = open + 1;
  let depth = 0;
  let quote = null;
  let elementStart = i;
  const elements = [];
  for (; i < src.length; i += 1) {
    const ch = src[i];
    if (quote) {
      if (ch === '\\') i += 1;
      else if (ch === quote) quote = null;
      continue;
    }
    if (ch === "'" || ch === '"' || ch === '`') quote = ch;
    else if (ch === '[' || ch === '{' || ch === '(') depth += 1;
    else if (ch === ']' || ch === '}' || ch === ')') {
      if (depth === 0) {
        const last = src.slice(elementStart, i).trim();
        if (last) elements.push(last);
        break;
      }
      depth -= 1;
    } else if (ch === ',' && depth === 0) {
      elements.push(src.slice(elementStart, i).trim());
      elementStart = i + 1;
    }
  }
  const body = src.slice(open + 1, i);
  const multiline = body.includes('\n');
  const indent = multiline ? (/\n([ \t]*)\S/.exec(body)?.[1] ?? '') : '';
  const closeIndent = multiline ? (/\n([ \t]*)$/.exec(body)?.[1] ?? '') : '';
  return { elements, end: i, multiline, indent, closeIndent };
}

function writeArray(elements, { multiline, indent, closeIndent }) {
  if (!multiline) return `[${elements.join(', ')}]`;
  return `[\n${elements.map((e) => `${indent}${e},\n`).join('')}${closeIndent}]`;
}

/** Find each `q({ ... })` block: yields [start, end) offsets of the object literal body. */
function* blocks(src) {
  const re = /\bq\(\{/g;
  let m;
  while ((m = re.exec(src))) {
    let i = m.index + m[0].length;
    let depth = 1;
    let quote = null;
    for (; i < src.length && depth > 0; i += 1) {
      const ch = src[i];
      if (quote) {
        if (ch === '\\') i += 1;
        else if (ch === quote) quote = null;
        continue;
      }
      if (ch === "'" || ch === '"' || ch === '`') quote = ch;
      else if (ch === '{') depth += 1;
      else if (ch === '}') depth -= 1;
    }
    yield [m.index + m[0].length, i - 1];
    re.lastIndex = i;
  }
}

const beforeQuestions = snapshot();
const beforeById = new Map(beforeQuestions.map((q) => [q.id, q]));

let rotated = 0;
const skipped = [];
const cursorByModule = new Map();
for (const file of fs.readdirSync(path.join(dir, 'questions')).filter((f) => f.endsWith('.js'))) {
  const filePath = path.join(dir, 'questions', file);
  const src = fs.readFileSync(filePath, 'utf8');
  let out = '';
  let cursor = 0;
  for (const [start, end] of blocks(src)) {
    const block = src.slice(start, end);
    const id = /\bid:\s*(['"`])([^'"`]+)\1/.exec(block)?.[2];
    const q = id && beforeById.get(id);
    if (!q || !(q.type === 'mcq' || q.type === 'output') || typeof q.answer !== 'number') continue;
    if (q.choices.some((c) => ANCHORED.test(c.text))) {
      skipped.push(id);
      continue;
    }
    const n = q.choices.length;
    const slot = cursorByModule.get(q.moduleId) ?? 0;
    cursorByModule.set(q.moduleId, slot + 1);
    const target = CYCLE[slot % CYCLE.length] % n;
    // Rotating left by k moves old index i to (i - k) mod n; pick k so the
    // correct choice lands on `target`.
    const k = (q.answer - target + n) % n;
    if (k === 0) continue;

    const choicesAt = block.search(/\bchoices:\s*\[/);
    const answerMatch = /\banswer:\s*(\d+)\s*,?/.exec(block);
    if (choicesAt < 0 || !answerMatch) throw new Error(`${id}: could not locate choices/answer in source`);
    const open = block.indexOf('[', choicesAt);
    const arr = readArray(block, open);
    if (arr.elements.length !== n) throw new Error(`${id}: parsed ${arr.elements.length} choices, expected ${n}`);
    const rotatedElements = [...arr.elements.slice(k), ...arr.elements.slice(0, k)];
    const newAnswer = (q.answer - k + n) % n;

    let next = block.slice(0, open) + writeArray(rotatedElements, arr) + block.slice(arr.end + 1);
    next = next.replace(/\banswer:\s*\d+/, `answer: ${newAnswer}`);
    out += src.slice(cursor, start) + next;
    cursor = end;
    rotated += 1;
  }
  out += src.slice(cursor);
  if (write && out !== src) fs.writeFileSync(filePath, out);
}

console.log(`${rotated} questions rotated, ${skipped.length} skipped (anchored choices): ${skipped.join(', ')}`);

if (write) {
  const afterQuestions = snapshot();
  const problems = [];
  const hist = new Map();
  for (const q of afterQuestions) {
    const b = beforeById.get(q.id);
    if (!b) problems.push(`${q.id}: missing before`);
    const strip = ({ choices, answer, ...rest }) => JSON.stringify(rest);
    if (strip(q) !== strip(b)) problems.push(`${q.id}: something other than choices/answer changed`);
    if (b.choices) {
      const same = [...b.choices.map((c) => c.text)].sort().join('\u0000') === [...q.choices.map((c) => c.text)].sort().join('\u0000');
      if (!same) problems.push(`${q.id}: choice set changed`);
      if (typeof b.answer === 'number' && b.choices[b.answer].text !== q.choices[q.answer].text) {
        problems.push(`${q.id}: correct choice text changed`);
      }
      if (Array.isArray(b.answer) && JSON.stringify(b.answer) !== JSON.stringify(q.answer)) problems.push(`${q.id}: multi/order answer changed`);
    }
    if ((q.type === 'mcq' || q.type === 'output') && typeof q.answer === 'number') hist.set(q.answer, (hist.get(q.answer) ?? 0) + 1);
  }
  if (afterQuestions.length !== beforeQuestions.length) problems.push('question count changed');
  console.log('position histogram after:', Object.fromEntries([...hist.entries()].sort()));
  if (problems.length) {
    console.error(problems.join('\n'));
    process.exit(1);
  }
  console.log('verified: choice sets and correct-choice texts unchanged for every question');
}

## 7. Windows risks

1. **Line endings are system-wide here.** `core.autocrlf=true` comes from `C:/Program Files/Git/etc/gitconfig`, so every clone on this machine is CRLF until `.gitattributes` says otherwise. `prettier --check` with `endOfLine: lf` fails on all 48 files today. After `.gitattributes` + the one-time re-checkout, Prettier, EditorConfig and git agree on LF; VS Code follows the file. The tree is already mixed: the other agent's new server files are LF (`git diff` warns "LF will be replaced by CRLF"), so PR 1 above should go first.
2. **`git add --renormalize .` is a no-op** (index is LF) — the plan is right; the re-checkout is what converts working trees.
3. **GitHub `windows-latest` runs `run:` in PowerShell** — `defaults.run.shell: bash` is required for the grep step and any `if`/`!`. Fixed in 6.16.
4. **Entry-point detection.** `process.argv[1]` and `import.meta.url` can differ in drive-letter case depending on the launching shell; `lint.js` compares case-insensitively on win32 (6.19). `pathToFileURL` alone is usually fine but not guaranteed.
5. **`cross-env`** is only needed where a script sets a variable inline (`start`). None of the new scripts do; CI sets `REQUIRE_SQLITE` through `env:`. `--env-file-if-exists=.env` is a Node flag, portable, and resolves against the cwd that `npm -w server` sets to `server/`.
6. **Globs.** `eslint .` and `prettier --check .` take no shell globs; `node content/lint.js` uses a forward-slash path that Node accepts on Windows. Nothing here passes a glob through cmd.exe.
7. **SQLite file locks.** Windows will not delete an open database. Any vitest test that opens a store must `store.close()` in `afterEach` before `rmSync`, with a per-test `mkdtemp`; `check.js` already does this. vitest 4's default `forks` pool loads the native module per worker, which is fine.
8. **Local time.** This machine is UTC-7, CI is UTC; streak/day-key tests must use local-time constructors (§2).
9. **`git ls-files` results:** `client/dist` and `server/data` are untracked and ignored (both `.gitignore` and `client/.gitignore`); nothing to renormalise there. `marketplace/data/*.db*` and `favicon.ico` are already `-text`; the `*.db*`/`*.ico` binary lines in `.gitattributes` make that explicit.
10. **Speed on this box.** `npm install` of ~150 packages took 7-11 min, `npm view` ~10 s per call, a jsdom project boot ~17 s. `check:all` will be slow locally; CI is the real gate. Not a correctness issue, but worth a line in CONTRIBUTING ("`npm test -- --project server` while iterating").
11. **Concurrent editing.** Two agents writing the same tree is the biggest practical risk right now: the DX PRs above touch `server/package.json`, `client/tsconfig.json` and the content files that are currently modified in the working tree. Sequence the commits.
